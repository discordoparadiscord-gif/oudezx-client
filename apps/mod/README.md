# Oudezx Client Mod

Um mod completo para Minecraft Fabric com recursos de utilidade e HUDs.

## 🌟 Recursos

### HUDs
- ✅ FPS Display
- ✅ Ping Display
- ✅ CPS Counter (Left/Right clicks)
- ✅ Coordinates Display
- ✅ Armor HUD
- ✅ Potion Effects HUD
- ✅ Keystrokes Display
- ✅ Scoreboard Display

### Mods
- ✅ FullBright (Aumenta brilho)
- ✅ Zoom (Press C para zoom)
- ✅ Freelook (Press F para olhar livremente)
- ✅ Motion Blur
- ✅ Toggle Sprint
- ✅ Toggle Sneak
- ✅ Waypoints (Marcar pontos no mapa)

## 📋 Pré-requisitos

- Java 17+
- Minecraft 1.20.1
- Fabric Loader
- Fabric API

## 🔧 Build

```bash
cd apps/mod
mvn clean package
```

O arquivo `.jar` será gerado em `target/`

## 🎮 Instalação

1. Coloque o JAR em `~/.minecraft/mods/`
2. Inicie o Minecraft com Fabric
3. O mod será carregado automaticamente

## 🔐 Controles

- **Right Shift**: Abrir menu principal
- **C**: Zoom
- **F**: Freelook
- **Sprint Key**: Toggle Sprint
- **Sneak Key**: Toggle Sneak
